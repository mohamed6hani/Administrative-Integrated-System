# Public demo maintenance

This checkout is the source-only Administrative Integrated System demo. Keep institutional names, logos, production records, real documents, credentials, machine paths and original Git history out of it.

Only fictional data generated by `tools/seed-demo.cjs` belongs in `.demo-data/`. Do not add legacy migration, external runtime paths or network binding to the demo. Do not commit `.demo-data`, `.platform-build`, dependency folders, databases, CSV exports, uploads, PDFs or image assets, except for the single reviewed project brief described below.

The user-approved documentation exception is `docs/Administrative-Integrated-System-Overview.pdf` only. It contains fictional demo screenshots with institutional branding and logos removed. The public-source checker pins its exact path and SHA-256; every replacement requires a fresh page/image review and an updated approved hash. All other PDFs and image assets remain excluded.

After code changes, run `npm run build`. Before publishing, run `npm run check:public`, `npm run build:check` and `npm test`. Add meaningful workflow/access/confinement tests when those behaviors change. Keep public demo credentials clearly labeled, and document disabled integrations honestly.
